# DBMS OTT Platform Project

## Overview
This project is a Database Management System (DBMS) for an OTT (Over-The-Top) streaming platform. It demonstrates how platforms like Netflix manage users, subscriptions, and content using a structured relational database.

---

## Objectives
- Design a relational database for an OTT platform  
- Manage users, subscriptions, and content  
- Perform CRUD operations (Create, Read, Update, Delete)  
- Execute SQL queries for real-world scenarios  

---

## Technologies Used
- Database: MySQL  
- Language: SQL  
- Interface: Python (Tkinter) / Command Line  
- Tools: MySQL Workbench, VS Code  

---

## Database Schema

### Tables Included:
- Users – Stores user details  
- Subscriptions – Stores subscription plans  
- Content – Movies and shows information  
- Watchlist – User saved content  
- Viewing History – Tracks watched content  

---

## Features
- Add and manage users  
- Store and retrieve content details  
- Manage subscription plans  
- Track user watch history  
- Perform insert, update, delete operations  
- Execute complex SQL queries  

---

## Sample Queries
- Retrieve all users  
- Display content based on genre  
- Find most watched content  
- Get subscription details of users
